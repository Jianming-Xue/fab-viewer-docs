# 用户管理 · User

| 项 | 内容 |
|---|---|
| 模块 | 模块 6 · 用户与安全管理 · **用户管理** |
| 使用者 | IT 运维（账号维护）；全部登录用户（自助改密） |
| 状态 | 需求骨架（沟通中） |
| 来源 | Halo「用户管理」重做 |

> 本期**仅本地账户**；`authType` 预留 `AD`（接入时登录走域校验、本地不存密码，对接口径后续另定）。
> **角色与策略解耦、都直接挂用户**：角色管功能访问权限（可多挂），Login Policy 管登录策略（挂一条，`01` §2.2）。

---

## 一、功能定位

| 项 | 内容 |
|---|---|
| 干什么 | 用户 CRUD；挂**多个角色**（权限并集）与**一条 Login Policy**；维护两个到期日；启用 / 停用；管理员重置密码；用户自助改密 |
| 形态 | 配置页（用户列表 + 表单弹框）＋ Oracle 表 `FabViewerUser` / `FabViewerUserRole` |

## 二、配置表

**`FabViewerUser`**

| 字段 | 说明 |
|---|---|
| `id` | 技术主键 |
| `username` | 登录账号 —— **唯一索引**（创建后锁定） |
| `passwordHash` | 密码哈希（仅 LOCAL；哈希算法在创建用户时由后端处理） |
| `displayName` | 昵称（显示名） |
| `email` | 邮箱（可空；通知预留） |
| `phone` | 电话号码（可空） |
| `authType` | `LOCAL` / `AD`（预留）—— 本期恒 `LOCAL` |
| `policyId` | **用户的 Login Policy**（直接挂一条；可空 = 默认策略；挂了停用的策略视同回落默认） |
| `accountExpiresAt` | **账户过期日期**：创建时按当时策略 `accountValidDays` 折算存档（`-1` ⇒ 空 = 永不过期）；编辑可改（续期） |
| `passwordChangedAt` | **密码上次修改时间**：创建 / 改密 / 重置时刷新 |
| `passwordExpiresAt` | **计算得到的密码过期日期**：改密时刻 + 当时策略 `passwordValidDays` 折算存档（`-1` ⇒ 空 = 永不过期）；策略变更不重算 |
| `mustChangePassword` | 强制改密标记：创建（初始密码）/ 重置后置 `true`；下次登录强制先进改密 |
| `enabled` | 停用 = 拒绝登录（会话即时失效口径归认证框架） |
| `updatedAt` / `updatedBy` | 审计 |

**`FabViewerUserRole`**（多对多关系表）

| 字段 | 说明 |
|---|---|
| `id` / `userId` / `roleId` | 唯一键 =（`userId`, `roleId`）；保存用户时**全删全插**该用户的挂载 |
| 挂载语义 | 只挂**启用**角色；停用角色视同未挂（不删关系行，恢复启用自动生效） |

## 三、页面逻辑

| 项 | 口径 |
|---|---|
| 进入页面 | 调 `page` 取第一页（每页 20，不分档） |
| 条件 | 账号 / 昵称（同一框模糊，或两框——视觉细节归原型）、Enabled 筛选 |
| 列（按序） | Username、Display Name、Email、Phone、Roles、Policy、Account Expires At、Password Expires At、Must Change Password、Enabled、Last Updated Time、Last Updated User + Action（编辑 / 重置密码 / 删除） |
| Roles 列 | 显示角色名集合（多角色并列；停用角色灰显） |
| Policy 列 | 显示挂载的策略名；未挂显示「默认」 |
| 两个到期日列 | 空显示「永不过期」；已过期标红（呈现细节归原型） |
| 添加 | 弹框：Username（唯一，创建后锁定）、Display Name、Email、Phone、角色**多选**（候选 = 启用角色）、Login Policy 下拉（候选 = 启用策略 + 「默认」）、初始密码（按该用户策略生成或手填，手填校验长度区间 + 字符构成）→ `mustChangePassword = true`；保存时按策略 `accountValidDays` 折算 `accountExpiresAt`、按 `passwordValidDays` 折算 `passwordExpiresAt`（`-1` ⇒ 空） |
| 编辑 | Username 锁定；其余可改；角色多选**整体覆盖**；换挂策略不影响已存档的两个到期日（§四）；`Account Expires At` 可查看 / 修改（账户续期） |
| 重置密码 | 弹框：生成随机密码（按该用户策略）或手填（校验长度区间 + 字符构成）→ 成功后 `mustChangePassword = true`、刷新 `passwordChangedAt` 并按**当时策略**重折算 `passwordExpiresAt` |
| 删除 | 弹框确认；连带删除该用户的 `FabViewerUserRole`（登录历史按 `username` 记、不删）；推荐**停用代替删除** |
| 自助改密 | 不在本页 —— 登录后右上角入口（旧密码 + 新密码 ×2，按该用户策略校验长度区间 + 字符构成，成功清 `mustChangePassword`、刷新 `passwordChangedAt` 并重折算 `passwordExpiresAt`） |

## 四、策略命中与到期日折算

- 该用户的**唯一策略** = `policyId` 挂的那条（未挂 / 挂了停用的 ⇒ 默认策略）—— 无合并计算。
- 折算时机：**创建**（两个到期日一起算）、**改密 / 重置**（密码两个值刷新）；换挂策略、改策略内容都**不重算存量**（`01` §2.4）。

## 五、接口清单

外壳一律走**统一响应包**。

| # | 接口 | Method | 用途 |
|---|---|---|---|
| 1 | `security-management/api/v1/auth/me` | `GET` | 当前登录用户：账号、昵称、角色、**权限并集**（菜单 / 按钮路径数组）—— 前端全局消费（策略内容不下发） |
| 2 | `security-management/api/v1/auth/change_password` | `POST` | 自助改密（旧密码 + 新密码） |
| 3 | `security-management/api/v1/user/page` | `GET` | 用户分页 |
| 4 | `security-management/api/v1/user` | `POST` | 新增（含初始角色挂载与策略挂载） |
| 5 | `security-management/api/v1/user` | `PUT` | 编辑（`id` 定位；角色整体覆盖；可改 `policyId`、`accountExpiresAt`） |
| 6 | `security-management/api/v1/user` | `DELETE` | 删除（入参仅 `id`） |
| 7 | `security-management/api/v1/user/reset_password` | `POST` | 管理员重置（入参 `id` + 新密码或空 = 后端生成） |

- 登录接口本身（含两个到期日与停用判定）归**认证框架层**，不在本清单（`00` §四）。
- 改密 / 重置成功出参回传 `mustChangePassword` 与两个到期日。
